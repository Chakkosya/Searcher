# Search Image

AstrBot 插件：同一张图片同时交给 AnimeTrace、SauceNAO、E-Hentai、Google Lens 和 Yandex 搜索。结果按相同页面去重，优先展示多引擎都命中的页面、明确的高相似度结果和包含原图的页面，取前三条发送。消息包含平台、匹配关键词、名称或账号（有数据时）及预览图；不展示页面链接，也不生成卡片。

## 安装

使用 AstrBot 4.23.2 或更新版本。将本仓库目录放到 AstrBot 的 `data/plugins/reverse_searcher_top3`，安装 `requirements.txt` 中的依赖并重启 AstrBot。可直接发送“以图搜图”“找鸡”或“搜图”加图片，也可回复一条含图片的消息提问。先发“搜图”、下一条单独发图片也会进入 AI 判断；等待两分钟，按同一会话和发送者承接。插件提供 `reverse_search_top3` 工具，由 AI 根据用户问题判断是否调用。

工具执行时会先发送“正在全网找图”，然后发送前三条结果。结果文字和预览图按名次交替排列。预览优先使用引擎给出的原图地址，失败时使用缩略图。

## 配置

在 AstrBot 插件设置中填写：

- `serpapi_key` 或 `zenserp_key`：Google Lens 所需，二者至少填一个。
- `saucenao_api_key`：SauceNAO 的 API Key，建议填写。
- `proxies`：服务器访问这些引擎需要代理时填写。
- `yandex_cookies`：Yandex 出现验证码时填写。
- `ehentai_cookies`：需要登录搜索时填写。
- `allow_third_party_image_host`：Google Lens 和 Yandex 搜索消息图片时需先把图片上传到临时图床；默认开启。
- `trigger_keywords`：默认 `以图搜图`、`找鸡`、`搜图`。

五个引擎会并发尝试。未配置 Google Key、遭遇验证码或某个引擎出错时，其余引擎仍返回结果，消息末尾列出未完成的引擎。

## 拒绝后的搜图

AI 会先判断是否调用工具。带图片的请求若被 LLM 以拒绝语句结束，或用户明确要求搜图而 LLM 未调用工具，插件会直接补调注册的 `reverse_search_top3` 工具。无图片的请求没有可搜索的输入。要让替换后的回复完整生效，建议关闭 AstrBot 的流式输出；流式模式中已发出的文字片段无法撤回。

## 已知限制

- 五个引擎的相似度含义不同，前三条是按可用证据排序的候选结果，不能把它们当作统一概率。名称与账号只取搜索结果明确给出的字段或页面地址中的公开账号路径。
- 部分引擎只提供缩略图，或预览图地址无法下载，此时该条结果会显示“预览图：暂无”。
- Google Lens 需要有效 Key。Yandex 的网页结果可能受到验证码或页面改版影响。
- 引用消息需由平台适配器提供被引用的图片组件；引用内容无法读取时，请重新发送图片。
- 普通群聊带图提问沿用 AstrBot 的唤醒规则；没有“搜图”指令时，需先唤醒机器人，AI 才会判断是否调用工具。
